# DeepSeek V4 tokenizer asset

`tokenizer.json.gz` is the unmodified official tokenizer JSON compressed with gzip (level 9). Both DeepSeek V4 Pro and Flash publish identical tokenizer bytes:

- [DeepSeek-V4-Pro](https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro/blob/b5968e9190ef611bbf34a7229255be88a0e937c1/tokenizer.json), revision `b5968e9190ef611bbf34a7229255be88a0e937c1`.
- [DeepSeek-V4-Flash](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash/blob/60d8d70770c6776ff598c94bb586a859a38244f1/tokenizer.json), revision `60d8d70770c6776ff598c94bb586a859a38244f1`.
- SHA-256 of the decompressed JSON: `8f9f37ca37fdc4f5fd36d5cf4d3b0e8392edb4e894fd10cc0d70b4957c8633cf`.
- The upstream MIT license is preserved in [LICENSE](./LICENSE).

To reproduce the asset from the repository root:

```sh
curl -fL https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro/resolve/b5968e9190ef611bbf34a7229255be88a0e937c1/tokenizer.json -o .cache/deepseek-v4-tokenizer.json
node --input-type=module -e 'import {readFileSync,writeFileSync} from "node:fs"; import {gzipSync} from "node:zlib"; writeFileSync("assets/deepseek-v4/tokenizer.json.gz",gzipSync(readFileSync(".cache/deepseek-v4-tokenizer.json"),{level:9}));'
```

The runtime lazily decompresses this local asset and runs the official sequence of Split and ByteLevel pre-tokenizers and BPE merges using `@huggingface/tokenizers`. It removes `added_tokens` and disables added special tokens to count literal message content as ordinary text. Message framing remains the meter's separate allowance.

The golden counts in [deepseek-v4-fixtures.json](../../tests/deepseek-v4-fixtures.json) were generated by Hugging Face Rust `tokenizers` 0.23.2: decompress the asset, set `data["added_tokens"] = []`, load `Tokenizer.from_str(json.dumps(data))`, and count `len(tokenizer.encode(text, add_special_tokens=False).ids)` for each fixture text.
